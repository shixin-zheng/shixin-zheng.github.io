Proposes two Davis–Yin three-operator splitting schemes for the defocusing Gross–Pitaevskii ground state whose every iteration inverts only a shifted Laplacian (or a shifted Laplacian plus the separable part of the potential), and proves, for monotone discrete Laplacians, global convergence to the unique positive discrete ground state from any positive normalized initial vector at any constant step size below an explicit threshold; 3D tests with up to 999<sup>3</sup> unknowns run on a single GPU.
